# TrailTreeTrip Next.js Website — Phase 1

A responsive Next.js App Router website with TypeScript, Tailwind CSS, SEO metadata, sitemap, robots configuration, mobile navigation and a demo enquiry form.

## 1. Requirements

Install Node.js 20.9 or later.

## 2. Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## 3. Add business details

Copy `.env.example` to `.env.local`, then update:

```env
NEXT_PUBLIC_SITE_URL=https://www.trailtreetrip.com
NEXT_PUBLIC_PHONE=+91XXXXXXXXXX
NEXT_PUBLIC_WHATSAPP=91XXXXXXXXXX
NEXT_PUBLIC_EMAIL=info@trailtreetrip.com
```

The WhatsApp number must contain the country code and digits only.

## 4. Current features

- Responsive homepage
- Visa and travel service cards
- Popular destination section
- Trust and brand content
- Enquiry form interface
- WhatsApp button
- Metadata for SEO and social sharing
- Dynamic `robots.txt`
- Dynamic `sitemap.xml`
- Mobile menu
- Accessible form labels and navigation

## 5. Before publishing

- Add the real TrailTreeTrip logo
- Add verified address, phone, email and domain
- Connect the enquiry form to email or CRM
- Add Google Analytics and Search Console
- Add Privacy Policy, Terms and Refund Policy
- Add individual SEO service and destination pages
- Review visa information before publication
